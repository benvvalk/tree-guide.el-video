** TODO =lispy=: for structural navigation (third party package)
- Emacs' built-in lisp navigation commands are a bit awkward:
  |-------+------------------|
  | key   | function         |
  |-------+------------------|
  | C-M-u | backward-up-list |
  | C-M-d | down-list        |
  | C-M-n | forward-list     |
  | C-M-p | backward-list    |
  |-------+------------------|
- =lispy= navigation keys are *way better*:
  |-----+-----------------+------------------------------------|
  | key | function        | note                               |
  |-----+-----------------+------------------------------------|
  | h   | lispy-left      | move to beginning of parent        |
  | f   | lispy-flow      | visit lists in order of evaluation |
  | j   | lispy-down      | move to beginning of next sibling  |
  | k   | lispy-up        | move to beginning of prev sibling  |
  | b   | lispy-back      | backward in navigation history     |
  | d   | lispy-different | jump to matching open/close paren  |
  |-----+-----------------+------------------------------------|
- =lispy= can do much more (i.e. structural editing commands)!
  - for full list of lispy keybinds:
    - do =M-x describe-mode= and search for "lispy"
  - see =lispy= author's own demo videos:
    - https://www.youtube.com/@abo5abo/videos
  - see also: =paredit=, =symex= packages
** TODO =hideshow-org=: for folding subtrees (third party package)
- =hideshow-org= is a small wrapper around built-in =hideshow=
- =hideshow='s default keybinds are insane:
  |-----------+------------------|
  | key       | command          |
  |-----------+------------------|
  | C-c @ C-e | hs-toggle-hiding |
  |-----------+------------------|
- =hideshow-org='s keybinds are much better:
  |-------+---------------------|
  | key   | command             |
  |-------+---------------------|
  | TAB   | hs-org/hideshow     |
  | S-TAB | hs-org/hideshow-all |
  |-------+---------------------|
